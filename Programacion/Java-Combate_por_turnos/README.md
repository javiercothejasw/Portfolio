# Combate por turnos (en desarrollo)
## Descripcion

Proyecto en Java donde se desarrolla el combate entre dos grupos de Luchadores y se obtiene un Ganador.

- Hay distintos tipos de Personajes (Guerrero, Mago)
- Un "Bando_1" se enfrenta a otro "Bando_2", cada Bando se integra de Personajes.
- El bando que elimine primero a todos los Personajes del bando contrario Gana.

En desarrollo: Mas Personajes y variantes de combate, interaccion del Usuario en los combates.

## Compilacion y Ejecucion
Se necesita instalar el JDK para compilar y ejecutar el codigo. En la consola de comandos se realizan las siguientes acciones:

### Compilacion

    javac src/main/*.java
### Ejecucion
Ubicados en la carpeta src/main

    java Main

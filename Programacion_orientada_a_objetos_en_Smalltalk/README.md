# Programacion orientada a objetos en Smalltalk

## Descripcion

Cada archivo es una Actividad distinta desarrollada en el entorno Cuis University en el lenguaje puramente orientado a objetos Smalltalk. 
En estas actividades se aplican conceptos fundamentales de la POO que son transmitibles a cualquier otro Lenguaje de programacion orientado a objetos.

## Conceptos aplicados

- Clases, subclases y instancias.
- Mensajes y Metodos.
- Polimorfismo, distintas implementaciones de un metodo que responden a un mismo mensaje.
- Patrones de diseño: Null Object, Method Object, Object Recursion, Compositte, Visitor, entre otros.
- Encapsulamiento y extensibilidad del codigo.
- TDD, Desarrollo guiado por pruebas

## Visualizacion de los archivos

Para poder visualizar y explorar los archivos se necesita el entorno Cuis University, es un entorno totalmente portable, se descarga, se descomprime y ya se puede utilizar. Link de descarga:

    https://sites.google.com/view/cuis-university/inicio?authuser=0

Ejecutamos el programa, arrastramos los archivos dentro de la interfaz, seleccionamos "File in", y los archivos ya se pueden visualizar en el entorno Cuis University.

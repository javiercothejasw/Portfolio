# Wazowski en busqueda de los papeleos

Minijuego ejecutado en la consola de comandos de Linux donde controlaremos al personaje Wazowski (W) para recolectar todos los papeleos(1-2-3-4) esparcidos a lo largo de 3 habitaciones(Mapas).

-Empezaremos con una cantidad inicial de Movimientos.

-El juego cuenta con herramientas y obstaculos que nos ayudaran o dificultaran la mision.

-Para Ganar el juego deberemos superar las 3 habitaciones.

-Deberemos encontrar todos los papeleos de una habitacion para pasar a la proxima.

-Perderemos el juego si nos quedamos sin movimientos o si somos eliminados por algun obstaculo.
